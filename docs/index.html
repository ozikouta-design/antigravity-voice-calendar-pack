なぜ「途中切れ」や「保存ミス」が起きないのか？（5つの品質ゲート）

      

      

        AIにただ「文字起こしして」と頼むだけでは、長い音声の後半を勝手に省略されたり、空ファイルのまま完了扱いになる事故が起きます。本ルールでは以下の5項目すべてに合格した音声だけを完了扱いにする安全設計を組み込んでいます。
      


      

        
          

            品質ゲート項目
            チェック内容
          

        
        
          

            AUDIO_ID_MATCH = true
            元音声ファイル名・通話相手名・録音日時が1対1で完全に一致していること。
          

          

            TRANSCRIPT_COMPLETE = true
            冒頭から終端まで通話全区間を無分割で網羅していること（途中の要約代用や中略は不合格）。
          

          

            TERMINAL_VERIFIED = true
            末尾の発話（「失礼します」「お疲れ様です」等の終了挨拶）が実音声の終端と一致していること。
          

          

            PERSISTENCE_VERIFIED = true
            Googleドライブへ保存した直後にファイルを再読込（読み戻し）し、0バイトや文字化けでないことを確認すること。
          

          

            CALENDAR_SYNC_VERIFIED = true
            次回アポ（時間枠予定）および顧客からの宿題（非公開の終日予定）が漏れなくカレンダー登録・台帳記録されていること。

よくある質問（FAQ）・運用のコツ

      


      

        
10分以上の長い通話や商談録音でも、事前に分割しなくて大丈夫ですか？

        

          はい、分割不要です。10分を超える長尺音声でも、無分割のまま一括投入して冒頭から末尾の挨拶まで1文字も欠落せずに取得できることを実証済みです。
        

      


      

        
社内共有のGoogleカレンダーを使っていますが、お客様からの細かい宿題やメモを他の社員に見られたくありません。

        

          お客様からの宿題（やること）は、公開設定を「非公開（private）」にした終日予定として自動登録されます。社内メンバーの画面には「予定あり（非公開）」としか表示されず、あなた本人のカレンダー画面でのみ「【宿題】〇〇様 - 用件」というタイトルと箇条書きのTODOリストが確認できます。
        

      


      

        
家族やプライベートの通話録音が混ざってしまったらどうなりますか？

        

          _brain/通話_除外リスト.txt に家族やプライベート相手の登録名を書いておけば、AIが文字起こしを行う前に自動検知し、文字起こしやカレンダー登録をスキップして 業務外除外_YYYYMMDD/ フォルダへ安全に退避します。
        

      


      

        
スマホの録音ファイル名はどんな形式にすればいいですか？

        

          スマートフォンの標準通話録音形式（例：通話 相手名_YYMMDD_HHMMSS.m4a や 音声 YYMMDD_HHMMSS.m4a）のままで問題ありません。文字起こし補助テキスト（.txt）がある場合も一緒に入れておけば、固有名詞や数字の照合に自動活用されます。
