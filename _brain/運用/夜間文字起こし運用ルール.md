# 夜間文字起こし＆カレンダー自動連携 運用ルール（正本）

---

## 1．基本方針――無分割ファースト ＋ アポ・宿題自動カレンダー連携

- **正式な文字起こしの主軸はAntigravity（Gemini 3.8）。** 原音声を無分割で投入し、冒頭から終端（通話終了・挨拶）まで逐語全文と要約・重要事項・決定事項・TODOを一括作成する。
- **長尺音声の分割は不要（無分割標準）。** 10分超の長尺音声も無分割一括処理で1文字の欠落もなく終端まで取得する。
- **全面禁止するのはWhisperのみ。** Whisper、faster-whisper、whisper.cpp等のWhisper系生成物は一切使用・混入させない。
- **追加課金APIは使用しない。** Antigravity内蔵のマルチモーダル音声直接認識により、追加APIキーや外部課金なしで実行する。
- **商談・訪問アポイントは時間枠予定として自動登録。** 通話・録音の会話内容から次回アポイント（訪問、商談、納品、打ち合わせ等）が検知された場合、Googleカレンダーへ時間枠付きの予定として自動登録する。
- **お客様からの宿題（やること）は非公開の終日予定として自動登録。** 通話・商談内で顧客から依頼された宿題・TODO・提出物等のアクションアイテムは、他のメンバーには内容が見えないよう非公開（Private）設定の「見出しをタイトルとした終日予定」として登録し、メモ欄にやることを全て箇条書きで記載する。
- **補助テキスト（.txt）は照合資料。** 補助テキストが存在する場合は固有名詞・数字の照合に活用するが、存在しない場合も音声単独で処理を止めずに完結させる。
- **名寄せ禁止・業務外除外の徹底：**
  - `_brain/通話_除外リスト.txt` に合致する音声は、文字起こし対象から除外して原本を `音声データ/文字起こし済み/通話音声/YYYY-MM/業務外除外_YYYYMMDD/` へ退避する。
  - 同姓同名・類似氏名を本人確認なしに勝手に名寄せしない。

---

## 2．標準処理フロー（毎日01:00、日本時間）

Antigravityのスケジュールタスク（Daily 01:00 AM）により毎夜自動実行する。

1. **検知と除外判定：**
   - `音声データ/未文字起こし/` 内の全音声を検知。
   - `_brain/通話_除外リスト.txt` と照合し、業務外音声は `業務外除外_YYYYMMDD/` へ安全移動。
2. **無分割全文文字起こし＋要約作成：**
   - 残りの業務通話を、Antigravityが直接聴取。
   - 逐語全文（話者分離: 山田 / 相手名）および通話要約（概要・重要事項・決定事項・TODO・次回予定）を生成。
3. **正式保存と読み戻し検証：**
   - 全文：`_brain/録音全文/通話 <相手名>_<日時>.md` に保存（対面録音は `音声 <日時>.md`）。
   - 要約：`_brain/通話要約/通話 <相手名>_<日時>_要約.md` に保存（対面録音は `音声 <日時>_要約.md`）。
   - 正式保存後に再読込し、ファイルサイズ（0byte排除）・文字化けがないことを検証。
4. **アポイント・宿題検知とカレンダー自動登録：**
   - 通話要約の「決定事項」「TODO」および会話全文から、
     1. **アポイント（商談・訪問・打合せ）：** 開始〜終了時刻を指定したカレンダー予定として登録。
     2. **顧客からの宿題（やること）：** 期日（未定時は翌営業日）の**非公開終日予定（Private）**として登録し、見出しをタイトルに、メモ欄にやることを全て箇条書きで記載（社内他メンバーには非表示）。
   - 登録履歴を `_brain/運用/外部ソース台帳/CALENDAR_MATCH_INDEX.jsonl` へ記録。
5. **原本移動（アーカイブ）：**
   - 読み戻し検証およびカレンダー処理が合格した音声原本のみ、`音声データ/文字起こし済み/` へ移動。
   - `未文字起こし/` フォルダの残数 **0件** を確認して完了。

## 3．フォルダー構造・格納ルール

| 種別 | 格納先パス | 命名規則・説明 |
| :--- | :--- | :--- |
| **逐語全文** | `_brain/録音全文/` | `通話 <相手名>_<日時>.md` または `音声 <日時>.md` |
| **通話要約** | `_brain/通話要約/` | `通話 <相手名>_<日時>_要約.md` または `音声 <日時>_要約.md` |
| **カレンダー台帳** | `_brain/運用/外部ソース台帳/` | `CALENDAR_MATCH_INDEX.jsonl`（アポイント・宿題カレンダー登録連携台帳） |
| **音声原本** | `音声データ/文字起こし済み/` | 文字起こし完了後の原本保持（通話は `通話音声/YYYY-MM/`、対面は `録音データ/YYYY-MM/`） |
| **除外音声** | `音声データ/文字起こし済み/通話音声/YYYY-MM/業務外除外_YYYYMMDD/` | 業務外として文字起こしをスキップした音声原本の保護 |

## 4．品質判定基準（Quality Gates）

- **AUDIO_ID_MATCH = true**：ファイル名・相手名・日時の完全一致。
- **TRANSCRIPT_COMPLETE = true**：冒頭から終端までの通話全区間を網羅。途中終了・要約代用は不合格。
- **TERMINAL_VERIFIED = true**：末尾の発話（「失礼します」「お疲れ様です」等）が実音声と一致。
- **PERSISTENCE_VERIFIED = true**：保存後、即時読み戻しによる実体確認（空ファイル0byteの排除）。
- **CALENDAR_SYNC_VERIFIED = true**：アポイント（時間指定）および顧客宿題（終日予定）の漏れなき登録・台帳反映確認（該当なしの場合は skipped と記録）。

## 5．アポイント＆宿題（やること）カレンダー登録仕様

### 5.1 アポイント（商談・訪問・打合せ）の登録仕様
- **予定種別**: 時間指定イベント（例: 14:00〜15:00）
- **タイトル**: `【<種別>】<相手名または社名> - <用件>`
  - 種別: `【商談】`, `【訪問】`, `【納品】`, `【打合せ】`, `【連絡】`
  - 未確定アポの場合: `【仮・要確認】【<種別>】...`
- **所要時間**: 明示がある場合はその時間。未指定時は標準60分（納品サポート等は90分、架電確認は15分）。
- **説明欄（メモ）**: 対象顧客名、用件詳細、通話要約リンク、決定事項の抜粋。

### 5.2 お客様からの宿題（やること）の登録仕様
- **予定種別**: **終日予定（All-day event）**
- **公開設定（Visibility）**: **非公開（Private: `--visibility private`）を必須標準** とする。社内共有カレンダーにおいて他のメンバーからはタイトル・メモ内容（箇条書き）が完全に非表示（「予定あり」または非公開扱い）となり、本人にのみ内容が表示される。
- **期日設定**:
  - 会話内で期日（「金曜まで」「今週中」「○日までに」）が指定されている場合 → その期日。
  - 期日指定がない場合 → 翌営業日（土日祝の場合は週明け月曜日）。
- **タイトル（見出し）**:
  - 見出しをタイトルとする。
  - フォーマット: `【宿題】<顧客名/相手先> - <用件の見出し>`
  - 例: `【宿題】株式会社サンプル商事 佐藤様 - 複数台割賦Excelフォーマット確認・送付`
- **メモ欄（説明 / Description）**:
  - **やることを全て箇条書き** で記載する。
  - フォーマット例:
    ```text
    【顧客・相手先】<会社名 / 担当者名>
    【発生日・元通話】<録音日時>（通話要約: _brain/通話要約/通話 ○○_要約.md）
    
    【やること（宿題事項）】
    - ○○○○
    - ○○○○
    - ○○○○
    
    【背景・補足】
    ・会話でのやり取り要点
    ```
