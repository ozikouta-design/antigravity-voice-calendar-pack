# 音声文字起こし＆Googleカレンダー自動連携 ルール

このプラグインが有効な環境では、`_brain/運用/夜間文字起こし運用ルール.md`（存在しない場合は `voice-transcription` スキルの手順）に従い、音声ファイルの無分割全文文字起こし・要約作成・Googleカレンダー連携を行う。

- 10分超の長尺音声も事前分割せず、冒頭から末尾の挨拶まで一言一句すべて文字起こしする。
- Whisper系ツールは一切使用しない。
- `_brain/通話_除外リスト.txt` に該当する相手の音声は文字起こしせず `業務外除外_YYYYMMDD/` へ退避する。
- 次回アポイントは時間枠予定として、顧客からの宿題（TODO）は非公開（`private`）の終日予定（タイトルは `【宿題】<相手先> - <見出し>`、メモ欄に箇条書き）としてGoogleカレンダーへ自動登録する。
- 5つの品質ゲート（`AUDIO_ID_MATCH`, `TRANSCRIPT_COMPLETE`, `TERMINAL_VERIFIED`, `PERSISTENCE_VERIFIED`, `CALENDAR_SYNC_VERIFIED`）すべてに合格した後にのみ、元音声を `音声データ/文字起こし済み/` へ移動する。
